# Kurinji — The Last Bloom: polygon visual library

This handoff catalogs the complete supplied ART_REFERENCE.md in one faceted 3D art direction. It includes101completed visual boards;20planned boards await generation after the daily image limit. PENDING.html contains their exact specifications, prompts and remaining correction notes. Open index.html to browse, search, inspect full images, compare two boards and check source coverage. The individual PNGs are 3840 ×2160. Native generated images are preserved at their original tool paths; delivery PNGs are upscaled where necessary, with native dimensions recorded in metadata.

## How to use the collection

Begin with the world/style boards, then the principal character turnarounds and location sheets. Compare peaceful, damaged and rebuilt states before modeling their shared base geometry. Use the props/nature sheets to build reusable kits. Lighting boards isolate the seven mood presets; effect boards show shape language, stages and decay. The twelve story images show how those pieces combine.

The art is a visual concept reference. Use the supplied numerical tables in this guide and the original source for coordinates, dimensions and material values. Generated annotations, perspective illustrations and proposed plans can have incidental count or scale drift; they should not override the source measurements.

## Art direction

Visible intentional polygon planes, expressive angular faces, faceted cloth folds, chamfered stone/wood/metal, simple material color blocking and atmospheric lighting. Major silhouettes and color relationships carry detail. Sacred northern slopes are cool and misty; the southern fortress is black iron/crimson/fire. Kurinji violet emission belongs to flowers, memory blossoms, petals and the player's special attack.

Primary setting is South Indian hill country: shola/eucalyptus mixed with the source conifers, plaster houses, clay tiles, thinnai porches, kolam and mango-leaf thoranam. The primary temple uses a modest stepped Dravidian-inspired tower while retaining the source platform/pillar/step specification. The current three-tier pagoda roof and five-color prayer flags remain explicitly labelled alternatives. Ganesha is the primary village-shrine choice; Murugan is an alternative study. Optional bridge/stream art is a proposal.

A simple iron-anvil army symbol is a design interpretation. Unspecified prop constructions, house-owner genders, proposed geometry and unknown ages remain interpretations rather than new story canon.

## Production use

Model shared architecture once, then create damage/rebuild swaps. Reuse the eleven-house kit's plaster/tile/door/porch modules with owner-specific props. Treat waiting and blooming Kurinji as states of the same plant. Reuse the six lantern and four brazier designs by instance. Keep small props separate from their enlarged studies. Use the character height table when retargeting skeletons and placing assets.

The library offers shape, color and staging targets rather than measured mesh topology. Triangle budgets, UVs, rigging, colliders and executable effects are implementation work for the game. The optional interface sheet is a visual proposal, not an assertion that the existing game has those layouts.
